# KBO 연감 과거 FA 입력

2026 KBO 연감 PDF 84~88페이지의 2000~2017년 계약 193건을 `kbo_player_movements`에 추가했다. 기존 2017년 공시 수집에는 해당 FA 시즌의 계약이 포함되지 않아 2017년 14건도 누락분으로 입력했다. 2018년 이후 기존 계약은 변경하지 않았다.

- 연도별 건수: 2000 5, 2001 6, 2002 4, 2003 4, 2004 13, 2005 11, 2006 14, 2007 10, 2008 6, 2009 11, 2010 8, 2011 2, 2012 17, 2013 11, 2014 16, 2015 19, 2016 22, 2017 14.
- 모든 레코드의 `player_id`를 기존 선수와 연결했다. 김태균은 한화 71752와 롯데 94415, 이승호는 1976년생 99137과 1981년생 70820을 구분했다.
- `year`는 원문 FA 적용 연도다. 계약 체결일이 없는 이 기록의 `event_date`는 NULL이며 API의 `date`에는 연도만 반환한다. 기존 공시 기록의 날짜 의미는 동일하다.
- 원문 계약 기간과 옵션은 `contract_term`, 최대 기간은 `contract_years`에 저장했다. 인센티브와 보상선수 표기를 상세 설명 및 원문 JSON에 보존했다. 구단 발표액이므로 `contract_registered_amount`는 NULL이다.
- 원화 184건, USD 4건, JPY 5건으로 원문 통화를 유지했다. 황재균 2017년 스플릿 계약은 MLB 기준 최대 310만 달러, 박재홍 2006년은 2년씩 각각 15억원으로 조건부 4년 최대 30억원을 저장했다.
- 이병규 2007년은 기간·총액 비공개이므로 둘 다 NULL이다. 이승엽 2004년은 연봉 2억엔만 기재되어 전체 총액은 NULL, 원문 연봉은 상세 설명에 보존했다. 미계약 최영필·이도형(2011), 노장진·차명주(2007)는 계약으로 입력하지 않았다.

입력 도구는 `prepare-historical-fa.py` 및 `apply-historical-fa.php`다. 계획·PDF·시각 확인 이미지·압축 스냅샷·검증 결과는 프로젝트 루트 `.contract-enrichment`에 보관한다. 백업 테이블을 생성하지 않았다.

전체 선수 연결 및 금액/기간 검증, 기존 행 전 컬럼 보존 검증, 재실행 추가 0건, 운영 선수 상세 API의 연도 표시, 실제 일일 크롤러 읽기 실행, 기존 계약 파서 테스트 6건을 확인했다. 운영 API와 일일 크롤러에는 날짜 미상 기록 처리를 최소 수정으로 반영했다.
