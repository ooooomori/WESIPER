# 나무위키 가족관계 추가 (2026-10-03)

출처: [KBO 리그/야구인 2세](https://namu.wiki/w/KBO%20%EB%A6%AC%EA%B7%B8/%EC%95%BC%EA%B5%AC%EC%9D%B8%202%EC%84%B8).

`kbo_player_family`에 73건을 추가했다. 기존 29건은 그대로 유지되어 총 102건이다. 표와 겹치는 기존 관계 13건은 중복 등록하지 않았다. 같은 아버지의 링크된 자녀끼리 형제 관계도 등록했다. 인물 문서로 확인한 김윤하·김명규 형제 관계를 포함한다.

표의 `/w/` 인물 링크를 기준으로 수집했다. 각주 링크만 있거나 이름에 인물 링크가 없는 대상은 제외했다. 링크 자체가 프로 입단 여부를 보장하지 않으므로 기존 선수 ID와 생년을 대조했다. 명단과 근거는 `data/player-family/namu-families.json`에 보관했다.

사용자가 별도로 지정한 김용우(72131)는 링크 없는 인물 제외 규칙의 예외로 포함했다. 김호인(87012)과의 부자 관계를 기존 이름·생년월일 확인 후 추가했다. 추가로 김동빈(60766)의 아버지 김용국(85412), 형 김동영(79952) 관계도 사용자 지정에 따라 포함했다. 구대성(93715)의 형 구대진(90003) 관계도 추가했다.

강도훈(52416)은 공식 KBO 검색·프로필로 신원을 확인한 후 `kbo_player_data`에 새로 등록했다. 공식 프로필의 2022년 삼성 소속 은퇴 선수이며 `is_kbodle=0`, `throw=우투`, `bat=우타`로 입력했다. 기존 선수 행은 수정하지 않았다.

박찬호는 메이저리거 ID 62761로 구분했으며 김윤하·김명규와의 관계는 인물 문서에 명시된 실제 촌수인 `5촌`이다. 박건우는 1998년 6월생 ID 51645로 구분했다. 조영준은 표의 2003년생 대학 선수와 DB의 1993년생 선수 62945가 달라 연결하지 않았다. 김성근·송진우 등 기존 KBO 데이터와 위키의 생일이 다른 경우 해당 선수 ID를 확인하고 기존 생일은 보존했다.

## 반영과 검증

`deploy/apply-player-family-wiki.php PRIVATE_DB_CONFIG`는 미리보기이며 `--apply`를 붙이면 반영한다. JSON 명단의 이름·생일을 현재 DB와 대조하고, 방향이 반대인 동일 쌍까지 중복·관계 충돌을 검사한다. 선수 및 가족관계 등록은 한 트랜잭션으로 처리한다.

기존 가족관계와 대상 선수의 모든 컬럼이 그대로인지, 추가된 쌍이 정확히 하나씩 존재하는지 확인한 후 DB 트랜잭션을 커밋했다. 반영 후 미리보기 결과 추가 0건, 이미 존재하는 관계 86건으로 재실행 중복 방지를 확인했다. 운영 프로필 API에서 강도훈↔강종필, 김명규↔김윤하, 김용우↔김호인, 김동빈↔김용국·김동영의 양방향 표기, 박찬호 5촌 표기, 조영준의 미연결 상태도 확인했다.

원본 HTML 캐시와 반영 전 압축 JSON 스냅샷은 Git에서 제외된 `.family-enrichment/`에 보존했다. 백업 테이블은 생성하지 않았다.
