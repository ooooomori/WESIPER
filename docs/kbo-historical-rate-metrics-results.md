# 1982~2000 비율 기록 및 투수 지표 보완

2026-10-02 운영·기존 프리뷰의 playerProfile API와 로컬 프로젝트에 반영했다. kbocandle 파일은 변경 전후 SHA-256이 동일하다. DB 설정 변경이나 재시작은 없었다.

## 공식 기록 보완

공식 [타자 기본1](https://www.koreabaseball.com/Record/Player/HitterBasic/Basic1.aspx)과 [기본2](https://www.koreabaseball.com/Record/Player/HitterBasic/Basic2.aspx)를 연도별 경기 수 내림차순으로 요청했다. 기존 BasicOld의 선수 ID·건수와 대조해 정규시즌 19년, 선수·시즌 3,648건을 검증했다. 득점·희생번트·희생플라이·루타·고의사구 및 OBP/SLG/OPS를 보완했다. total/team 양쪽 범위의 DB 행 7,296건을 수정했고 신규 행은 만들지 않았다. 팀 필터 행은 합산하지 않는다.

과거 포스트시즌은 Basic1이 선택한 시리즈와 달리 정규시즌 기록을 반환했고 Basic2는 지원 응답을 주지 않았다. 대조 검사로 걸러냈으므로 포스트시즌 희생플라이와 해당 출루율·OPS는 NULL을 유지한다. 장타율은 확인된 안타·2루타·3루타·홈런에서 계산한다.

1982~1985 정규시즌 공식 연간 OBP는 분모에 희생플라이를 제외한다. 이 규칙을 적용해 공식 연간 비율 3,648건이 모두 일치했다. 통산 OBP는 전체 희생플라이를 포함하는 표준 분모로 재계산한다. 연간 비율을 평균하지 않는다. 권두조(95576)의 1982 OBP는 .331, 통산 OBP/SLG/OPS는 .297/.266/.563이다.

## FIP와 ERA+

공식 투수 시즌 합계의 정규시즌·준플레이오프·플레이오프·한국시리즈를 각각 연도와 시리즈 ID로 묶어 리그 기준값을 계산한다. total 범위만 읽어 중복을 제외한다. 이닝은 아웃 수를 사용한다.

- FIP = `(13×HR + 3×(BB+HBP) − 2×SO) / IP + C`
- C = `리그 ERA − (13×리그 HR + 3×(리그 BB+리그 HBP) − 2×리그 SO) / 리그 IP`
- ERA+ = `100 × 리그 ERA / 선수 ERA`

ERA+는 기존 API와 일관된 리그 평균 기준이며 구장 보정을 추가하지 않는다. 통산 FIP 상수와 ERA+ 리그 ERA는 선수의 연도별 투구 이닝으로 가중한다. 기존 2001년 이후 기록과 합칠 때도 같은 가중 합계를 전달한다. 필요한 기록이나 리그 기준값이 빠지면 NULL을 유지한다. 이닝 0이면 두 지표 모두 NULL, 자책점 0이면 ERA+는 NULL이다. 기존 기간의 자료 누락을 추정 보충하지 않는다.

황태환(10082)의 통산 FIP 3.86, ERA+ 94를 운영 응답에서 확인했다. 1989년 자책점 0인 시즌은 FIP 3.57, ERA+ NULL이다. 과거·현재 기록이 섞인 선수도 가중 합계 수식을 검증했다.

## 검증과 보관

- 공식 연간 타자 비율 3,648건 일치, 실패 0건.
- 시즌 합계 DB 타자 10,028행·투수 5,536행 대조, 불일치 0건. 원문 1,049개 SHA-256 검사.
- 리그 전체 투수 FIP=ERA, ERA+=100 정규화 검사 통과.
- 운영 HTTP 선수 조회 7건 및 todayGames/teamRank 정상 JSON 확인.
- PHP 문법, Python 구문 및 배포·프리뷰 코드 18개 경로 검사 통과. 주요 계산·백필 코드의 로컬/서버 해시 일치.
- 로컬 playerProfile의 리그별 순위 선택 및 player-rankings의 ERA+ 순위 확장이라는 별도 변경은 보존했다. 이번 배포에는 그 확장을 포함하지 않았으며, 기존 배포본과 이번 계산 변경의 일치 여부를 확인했다.
