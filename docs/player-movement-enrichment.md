# 선수 이동 ID 및 계약 보강 (2026-10-02)

운영 `kbo_player_movements`에 실제 선수의 누락 ID 1,220건을 채웠다. 현재 총 5,379건이며, 남은 NULL 17건은 모두 `신인(지명권)` 트레이드다. 아직 특정 선수로 확정되지 않은 지명권에 선수 ID를 만들거나 붙이지 않았다.

이름뿐 아니라 개명 전 이름, 당시 구단, 1·2군 경기 기록, 생년월일, 입단 시점, 공식 프로필, 등번호와 당시 기사를 대조했다. 삼성의 좌완 이승현(51454)과 우완 이승현(60146), LG 김대현(66145)과 개명한 김단우(51109)를 구별했다. 에디튼 표기는 애디튼(67559), KT의 안승환 오타는 당시 군보류 포수 안승한(64011)으로 연결했다. 이동 공시 원문은 수정하지 않았다.

## 계약 컬럼

| 컬럼 | 의미 |
| --- | --- |
| `contract_years` | 연장 조건을 포함한 최대 연수. 확정 보장 연수와 다를 수 있음 |
| `contract_term` | `2+1년`, `2+1+1년` 등 조건을 유지한 기간 표기 |
| `contract_total_amount` | 발표된 최대 총액, 원 단위. 발표 총액에 포함된 옵션도 포함 |
| `contract_registered_amount` | KBO 연감에 실린 계약서 등록 금액. 발표액과 분리 |
| `contract_currency` | 이번 보강은 모두 `KRW` |
| `contract_details` | 보장·옵션·옵트아웃·군복무에 따른 연장 조건 등 확인된 설명 |
| `contract_source_url` | 공식 연감의 해당 PDF 페이지 및 보완 기사 URL. 복수 URL은 줄바꿈으로 구분 |
| `contract_verified_at` | 검증 시각(UTC) |

기존 FA/해외 복귀 FA 계약 160건을 보강하고, 비FA 다년계약 23건과 홍건희의 2026 KIA 자유계약 1건을 새로 추가했다. FA 자격취득 및 방출을 뜻하는 자유계약선수 공시에 계약액을 붙이지 않았다. 기존 이동 날짜는 KBO 공시 날짜를 보존하며, 새로 조사한 계약은 구단 발표 날짜를 사용했다. 취소된 송성문 계약이나 FA로 전환된 오지환 계약은 중복 추가하지 않았다.

주요 근거는 [KBO 2026 연감](https://6ptotvmi5753.edge.naverncp.com/KBO_FILE/ebook/pdf/2026_%EC%97%B0%EA%B0%90.pdf#page=81)의 2018~2026 FA 표다. 해외 복귀 김현수의 2018 계약은 [LG 공식 발표](https://www.lg.co.kr/media/release/8600), 이지영의 2026 다년계약은 [SSG 공식 발표](https://www.ssglanders.com/media/news/detail?idx=19830) 등으로 보완했다. 선수별 추가 근거는 `deploy/movement-contract-research.py`에 있다.

2019년 이후 연감은 계약서 금액 기준이므로 발표 최대액과 다를 수 있다. 이용규·최진행·윤규진·신본기·김민식 등의 발표액을 별도 보완했다. 이성열은 기본 2년 14억원에 구단 연장 1년 6억원, 구창모는 조건에 따라 6년 125억원 또는 군복무에 따른 연장을 포함하는 7년 최대 132억원이다. `contract_years`와 총액만으로 확정 지급액을 계산하면 안 된다.

## 적용 및 검증

- `deploy/apply-movement-identities.php`: 선수 ID만 변경하고 모든 다른 컬럼이 그대로인지 트랜잭션 안에서 대조.
- `deploy/apply-movement-contracts.php`: 컬럼 추가, 기존 계약 보강, 출처 기반 해시 키로 신규 계약 추가. 기존 원문 컬럼 보존 및 모든 계약 ID·기간·총액 확인.
- 두 적용기를 재실행한 결과 갱신·삽입 0건. 신규 계약 중복 없음.
- 원격 `import_player_movements.py --write` 검증 통과. 공식 이동 5,355건의 원문 필드를 검증하면서 조사로 추가된 24건을 보존함.
- `crawler/movement_identity_overrides.json`은 공식 `source_key`와 날짜·유형·구단·이름을 함께 검증해 다음 수집에서도 ID가 다시 비워지지 않도록 한다.

변경 전 데이터와 검증 결과는 `.contract-enrichment`에 압축 파일로 보관했다. DB 백업 테이블을 추가하지 않았으며 기존 HTML 캐시는 보존했다.

## 매일 자동 실행

2026-10-02 운영 서버 크론에 `30 2 * * * /home/bitnami/wesiper/run_daily_kbo.sh movements`를 설치했다. 서버 및 실행기 시간대는 `Asia/Seoul`이며 기존 02:00 경기 수집은 유지된다.

`crawler/daily_movement_contracts.py`는 현재 연도의 공식 선수 이동 API를 매번 새로 조회하고, 연초에는 직전 연도도 함께 확인한다. 과거 HTML 캐시와 보강 계약 필드는 유지한다. 새 이동의 ID는 검증된 source key, 현재·이전 이름, 생년월일·입단 시점, 해당 연도 1·2군 구단 기록 및 등번호로 연결한다. 아직 DB에 없는 선수는 공식 검색 결과와 프로필의 이름·구단이 정확히 일치할 때만 추가한다.

별도로 KBO 뉴스에서 최근 14일의 `계약` 기사를 검색한다. 선수·구단·기간·총액이 같은 발표 문단에서 명확하게 확인되면 기존 계약을 보강하거나 새 계약을 추가한다. 과거 계약 회고, 제안·협상·추정, 동명이인 및 기존 조건과 충돌하는 기사는 자동 입력하지 않는다. 발표를 먼저 저장한 뒤 공식 이동 공시가 도착하면 같은 계약을 두 개 만들지 않고 공식 출처로 승격한다. 조건부 기간과 최대 총액을 보존한다.

로그는 `/home/bitnami/wesiper/logs/movements-YYYY-MM-DD.log`, 검토 대기 항목 및 최근 결과는 `/home/bitnami/wesiper/daily-movement-contracts/last-run.json`에 기록한다. 금액이나 기간이 공개되지 않은 기사도 검토 목록에 남으므로, 기사 발견 자체가 계약 데이터 추가를 뜻하지 않는다. 동일 작업 중복 실행은 별도 flock으로 막으며 실패 시 해당 실행의 DB 변경은 롤백한다.
