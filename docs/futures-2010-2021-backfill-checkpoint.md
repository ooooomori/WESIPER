서버 코드는 `/home/bitnami/wesiper`, 원문·응답 캐시와 체크포인트는 `/home/bitnami/wesiper/official-futures-2010-2021`에 있습니다. 연도별 `write-receipt.json`에 경기별 커밋 목록이 있고, 완료한 경기를 재작성하지 않습니다. 임시 DB 테이블을 만들지 않았습니다.

각 연도의 일정 원문, 박스스코어 HTML, 공식 API 대체 응답, 선수 일자별 기록은 gzip으로 보관합니다. 수정 후에는 실패 경기만 재검증했습니다. 실행 중 실패는 전체 목록으로 모았습니다. 선수 이름 변경은 ID 충돌로 취급하지 않았고 경기에는 당시 이름을 유지했습니다.

올스타전 선수 ID 근거는 `futures_allstar_rosters.json`, `futures_allstar_identity_resolutions.json`에 있습니다. 2018년 LG 김태형의 두 후보는 공식 [출전 자격 공지](https://www.koreabaseball.com/Schedule/Allstar/News.aspx?bdSe=7085)와 공식 프로필 입단년도(67122: 18LG, 62918: 12NC)를 대조해 구분했습니다. 공지와 두 프로필 HTML도 `2018/allstar-identity`에 캐시했습니다. 박주홍은 공식 부모 데이터의 개명 정보로 박성웅(ID 68703)과 동일 선수임을 확인했습니다.

공식 원문 `홀드` 4,551행은 `홀`, `무` 1,012행은 NULL로 정규화했습니다. 수정은 새로 반영한 3,228경기 내 투수 결과 필드만 대상으로 경기별 커밋했습니다. 원문 캐시는 그대로이며 재개 시 DB 결과를 먼저 대조합니다. 승·패·홀·세 외의 결과 값 검사는 최종 0건입니다. 현재 연도 일일 크롤러의 파서는 변경하지 않았고, 과거 수집 전용 래퍼에서만 정규화합니다.

전체 범위 밖 연도별 행 수 비교, 타석 인덱스 연속성, 필수 NULL 검사, 중복, 투수 등판 순서, 동일 경기 양 팀 선수 ID 검사는 통과했습니다. 투수 누락 경기 `20120601SKPL0`는 타자·일정을 저장하고 투수 기록 및 상대 투수 컬럼만 비웠습니다.

DB 메모리 설정 파일은 원본과 같고 실제 버퍼는 16MB, 이벤트 스케줄러는 ON입니다. 운영 `todayGames.php`, `teamRank.php`는 HTTP 200과 유효한 JSON·오류 없음으로 확인했습니다. 로컬·서버 관련 코드의 SHA-256 일치와 서버 Python 구문 컴파일 결과는 `code-sync-verification.json`에 보관합니다.

후속 보정의 상세 설정은 `crawler/futures_history_user_corrections.json`, 운영 DB의 실제 행 대조 결과는 `crawler/futures_user_correction_verification.json`과 서버 캐시의 `user-correction-verification.json`에 있습니다. 28경기 29개 빈 타석은 사용자 지시에 따라 일반적인 `아웃`으로 저장했으며 정확한 공식 타석 결과를 복원한 것은 아닙니다. 공식 일정·박스·API 원문은 그대로 보존했습니다. 선수별 타수 부족분과 타순을 대조해 교체 선수를 구분했고, 타순이 다음 이닝으로 넘어가는 두 경기의 누락 위치도 조정했습니다.

`20100819LGSK0`는 사용자 추가 답변에 따라 손인호의 9회 우중3을 결승타로 저장했습니다. `20150723OBLG0`는 양원혁의 4회 우안, `20160409PLSK0`는 이경록의 4회 좌2로 저장했습니다. 황성일→황선일, 오영진→오명진은 비고 오타만 고쳤습니다. 도루자·주루사 선수 ID 79196·64004·76869는 사용자가 지정한 실제 행에 각각 연결했습니다.

`20200506KTHH0`의 최초 실패는 HTML 이름 김경민의 ID 판별 실패였습니다. 공식 API는 같은 타순·결과·합계를 현재 이름 김범으로 표시했고, 기존 실패 보고에는 API에서 발생한 결승타 이름 불일치만 남아 있었습니다. 공식 일자 기록 ID 50013의 2020-05-06 한화전 AB 3·H 3·RBI 4·R 2를 대조해 확정했습니다. 경기 행에는 당시 이름 김경민을 유지하고 6회 중안 행에 결승타를 저장했습니다.

반영 전 전체 DB 백업은 서버 캐시의 `recovery-backups/operating-db-20261001T111047Z.sql.gz`에 있습니다. 서버와 PC 임시 폴더의 별도 사본 체크섬을 확인했습니다. SHA-256: `5e9955110eddc410dbd1f3cc8af19a574973045b9b0cbf11c51fdf41faea8808`. 실제 복원 시험은 수행하지 않았습니다.

추후 미해결 경기의 공식 근거가 확보되면 해당 경기만 검증하고 실패 목록에서 해제합니다. 실패 목록·계획을 수정하는 작업과 운영 반영을 동시에 실행하지 않습니다. `write_futures_history.py --start-year YYYY --end-year YYYY --write`는 해당 연도 기존 커밋 체크포인트를 건너뛰고 새로 확인한 경기만 한 경기씩 저장합니다. `--write` 없는 사전 준비 명령으로 기존 백필 시작 시점 자료를 덮어쓰지 않습니다.
