# 선수 연도별 기록

- `part=year-records&type=all`은 타자·투수의 기본/심화/주루·이닝 지표와 `fielding` 수비 기록을 함께 반환한다. 프런트는 선수별 응답을 새로고침까지 보관하며 세부 탭 전환으로 재요청하지 않는다.
- `age`는 해당 연도 7월 1일 기준 만 나이이며 기본 탭의 팀별 하위 행에도 동일하게 적용한다. 나이는 기본 탭에만 표시하며 통산 행에는 나이와 포지션을 표시하지 않는다.
- `null`, 누락 데이터, 분모 0은 빈칸이다. 확인된 0은 0으로 표시한다. 2루도루/3루도루/홈스틸 컬럼은 표시하지 않는다.

## 수비

- `kbo_fielding_2001_2025`의 `p_no`로 조회한다. 연도·팀별 포지션 행을 묶어 두 식별 셀을 병합한다.
- `G`, `GS`, `p_pos`, `IP`, `FPCT`, `CS%`를 경기/선발/포지션/이닝/수비율/도루저지율로 표시한다. `CS%`는 이미 퍼센트 단위이다.
- 통산은 포지션별 경기·선발·이닝을 합산한다. 수비율과 도루저지율은 분모가 없으므로 통산 값을 빈칸으로 둔다.
- 지명타자는 kbo_season_records의 1군 정규시즌 포지션에서 경기별로 중복을 제거해 집계한다. 2001~2025년만 표시하며, 지명타자의 이닝과 수비율·도루저지율은 빈칸이다.

## 타자

- 사용자 지정 wOBA: `(0.7*(BB-IBB+HBP)+0.9*(1B+ROE)+1.25*2B+1.6*3B+2*HR+0.25*SB-0.5*CS)/(PA-IBB-SH)`. `고4` 등은 IBB, 희생번트 결과는 SH, `실`로 끝나는 결과는 실책 출루(ROE)로 센다. 공식 KBO 연도별 가중치 wOBA와는 구분한다.
- Spd는 [사용자가 지정한 Speed Score 공식](https://en.wikipedia.org/wiki/Speed_Score)의 F6을 제외한다. F1~F5 각각을 0~10으로 제한한 뒤 평균을 낸다.
- 순출루율은 OBP-AVG, 순장타율은 SLG-AVG이며 반올림 전 수치로 계산한다.
- BABIP는 `(H-HR)/(AB-K-HR+SF)`, BB%/K%는 타석 기준이다.
- 땅볼/뜬공은 `땅`/`병`으로 끝나는 아웃 수를 `비`/`파`로 끝나는 아웃 수로 나눈다. 희생플라이를 포함하고 직선타는 제외한다. 소수점 두 자리로 표시한다.

## 투수

- 이닝은 아웃 수로 변환하여 계산한 뒤 야구 이닝 표기로 돌려준다. `6.2`를 6.2이닝으로 계산하지 않는다.
- 선발은 등판 순서 1, 구원은 순서 2 이상, 마무리는 팀의 마지막 등판 순서인 구원 투수이다. 등판 순서가 누락되면 관련 집계는 `null`이다.
- QS: 선발 6이닝 이상/3자책 이하, QS+: 선발 7이닝 이상/3자책 이하, DS: 선발 8이닝 이상/1자책 이하. 더 높은 조건도 하위 조건의 집계에 포함된다.
- 완투는 종료 점수가 확인된 경기에서 팀의 유일한 투수로 선발 등판한 경우, 완봉은 그중 실점 0인 경우이다.
- K%/BB%는 상대 타석 기준이며 피안타율/피출루율/피장타율/BABIP는 상대 타석 결과로 계산한다. B/9는 9이닝당 볼넷이다.
- [FIP](https://library.fangraphs.com/pitching/fip/): `(13*HR+3*(BB+HBP)-2*K)/IP + C`. C는 시즌별 DB의 KBO 1군 정규시즌 전체 ERA와 HR/BB/HBP/K/IP로 산출한다. 리그 문맥은 수집 완료 리비전과 시즌 범위별로 캐시한다.
- ERA+는 구장 보정 없이 `100*리그 ERA/선수 ERA`로 계산한다. 통산 FIP 상수와 리그 ERA는 선수의 연도별 이닝으로 가중한다. 리그 계산에 필요한 기록이 없으면 빈칸이다.

## 시즌 선택

- type=all은 정규시즌 외에 seasons.preseason/postseason/futures에 모든 연도의 타자·투수 기록을 포함한다. 시즌 선택으로 재요청하지 않는다.
- 1군은 시즌별 날짜 범위, 퓨처스는 league_level=2의 연도별 기록을 사용하고 올스타전을 제외한다. 리그 비교 지표도 해당 시즌·리그를 기준으로 계산한다.
- 수비 기록은 정규시즌에만 제공한다. 선수와 기록 종류에 해당 시즌 기록이 없으면 선택 항목을 비활성화한다.

## 주요 기록 응답 최적화

- 프로필 → 주요 기록 → 순위를 우선 조회한 뒤 연도별 전체 기록을 선조회하여 로컬 PHP 서버의 직렬 요청 대기를 줄인다.
- 주요 기록 계산 결과는 선수·타자/투수·은퇴 상태·KST 날짜·시즌 범위별 서버 캐시를 사용한다. 크롤러 데이터 리비전 변경 또는 5분 경과 시 다시 계산한다.
- 은퇴 선수의 마지막 소속팀 조회는 인덱스로 MAX(game_date)를 먼저 구한 후 그 날짜의 경기만 정렬한다.

## 표 정렬과 피OPS

- 연도·팀을 제외한 헤더 클릭으로 내림차순/오름차순을 번갈아 적용한다. 새 컬럼의 첫 클릭은 내림차순이다. 누락값은 항상 마지막, 통산은 하단에 유지한다.
- 정렬 초기화는 원래 연도 순서와 연도 간 갭을 복원한다. 정렬 중에는 연도 갭을 표시하지 않는다. 수비는 포지션 행 전체를 정렬하고 연속된 연도·팀 셀만 병합한다. 캐시 원본을 수정하거나 재요청하지 않는다.
- 투수 피OPS는 반올림 전 피출루율+피장타율을 합산해 소수점 세 자리로 표시한다. 계산할 자료나 분모가 없으면 빈칸이다.

## 개요의 리그 선택

- 울산 소속은 올해 퓨처스 기록을 우선하며, 없으면 가장 최근 1군 정규시즌 기록을 사용한다.
- 1군 정규시즌 기록이 없으면 최신 퓨처스 시즌을 사용하고, 은퇴 선수는 퓨처스 통산을 표시한다. 양쪽 모두 기록이 없으면 영역을 숨긴다. 퓨처스 올스타전은 제외한다.
- 주요 기록·최근 5경기에 퓨처스 캡션을 표시한다. 이전 연도는 yyyy 시즌 퓨처스리그로 표시하되, 통산 주요 기록 캡션은 퓨처스리그로만 표시한다. 퓨처스 주요 기록에는 1군 순위를 붙이지 않는다.
- 투수 주요 기록 두 번째 줄은 이닝·삼진·WHIP·ERA+다. ERA+는 선택된 리그의 연도별 ERA를 이닝으로 가중해 계산한다.

- 주요 기록 ERA+ 순위는 해당 리그 안에서 내림차순으로 집계하고 동점은 공동 순위로 표시한다. 시즌은 팀 경기 수 이상의 이닝, 통산은 1,000이닝 이상을 기준으로 한다. 계산 불가 값은 순위에서 제외한다.
- 순위 API의 league 파라미터는 1(1군, 기본값) 또는 2(퓨처스)이며, 퓨처스 ERA+ 순위는 올스타전을 제외한 별도 집계다. ERA+ 순위 캐시는 데이터 리비전 변경 또는 5분 경과 시 갱신한다.

- 경기 탭의 올해 연속 기록이 시즌 첫 출전까지 이어지면 이전 1군 정규시즌을 최신순으로 조회해 끊기는 경기 직전까지 경기 수와 시작일을 확장한다. 성공·실패 모두 적용하며, 시범경기·포스트시즌·퓨처스는 포함하지 않는다. 도루 시도가 없는 해의 회색 기록은 과거의 마지막 도루 시도 직전까지 계산한다.
