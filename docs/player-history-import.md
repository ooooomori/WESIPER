# 해외·울산 선수 상태와 역대 타이틀홀더

2026-09-28 운영 DB에 적용했습니다. `kbo_player_data`는 6,002명이며 `kbo_player_titleholder`는 660건입니다. 기존 API와 사용자 수정 이벤트를 검증했고 이벤트 본문은 변경하지 않았습니다.

울산 웨일즈 선수 43명은 `team='울산'`, `is_kbodle=4`로 저장했습니다. 기존 선수 22명을 연결하고 없는 선수 21명을 추가했습니다. 군 입대 명단의 한찬희·박태현 2명을 포함하며 코치와 이전 소속 선수는 제외했습니다. 모두 KBO 공식 선수 ID를 사용했습니다.

| player_id | INT, NOT NULL | kbo_player_data.player_id 외래 키 |

`(player_id, type, year)`는 UNIQUE이며 `(year, type)` 인덱스를 추가했습니다. 공동 1위는 선수마다 한 행으로 저장합니다. PK는 1~660이고 수상 선수는 239명입니다. 채병용(71845)의 2008년 승률은 `0.833`으로 저장했습니다.

## 출처와 검증

요청한 나무위키 원본의 직접 접근이 제한되어 동일 문서의 `m.namu.moe` 열람본을 사용했습니다. 확인한 선수단 문서는 2026-08-03, 투수 문서는 2026-08-05, 타자 문서는 2026-08-15 수정본입니다.

- [울산 웨일즈 선수단](https://namu.wiki/w/울산%20웨일즈/선수단)
- [역대 투수 타이틀홀더](https://namu.wiki/w/KBO%20리그/역대%20타이틀홀더/투수)
- [역대 타자 타이틀홀더](https://namu.wiki/w/KBO%20리그/역대%20타이틀홀더/타자)
- [KBO 공식 역대 투수 기록](https://www.koreabaseball.com/Record/History/Player/Pitcher.aspx)
- [KBO 공식 역대 타자 기록](https://www.koreabaseball.com/Record/History/Player/Hitter.aspx)
- [KBO 선수 검색](https://www.koreabaseball.com/Player/Search.aspx)

공식 역대 기록 페이지의 13개 부문은 연도·공동 수상자·기록을 대조했습니다. 그 페이지에 없는 홀드·승률·승리타점은 요청한 문서의 연도별 표를 사용했습니다. 서로 다른 수치 10건은 KBO 공식 기록을 우선했으며 상세 비교는 `data/player-history/source-notes.json`에 있습니다. 울산 43명과 수상자 239명의 ID·생일을 공식 프로필과 대조해 동명이인을 구분했습니다. 신규 최지만과 서영준의 생일도 공식 프로필을 우선했습니다.

적용 데이터는 `data/player-history/`의 JSON에 보관합니다. import는 외부 설정을 서버에서 읽으며 DB 비밀번호를 데이터 파일에 담지 않습니다. 전체 선수 백업, 대상 데이터 해시, 원본 DDL, 이벤트 정의를 저장한 뒤 적용하고 트랜잭션 안에서 검증했습니다.

검증 결과:

- 타이틀홀더 660건과 대상 선수 47명, 신규 선수 21명 모두 일치.
- 대상 외 선수의 값 보존 확인. API가 갱신하는 `img`는 비교에서 제외.
- 새 상태 선수 47명의 프로필과 크보들 제외 동작 확인.
- 해외 4명·울산 하재훈의 캔들 소속팀과 오늘의 정답 확인.
- 기존 API 비교 12건, 공개 빙고판, 구 URL, 잘못된 ID, 은퇴 필터, 랜덤 선택 20회 통과.
- 사용자 수정 `KBODLE_GEN` 정의가 적용 전후 동일함을 확인.
