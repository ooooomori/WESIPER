# 호주 국가대표 경력 추가

`deploy/add-australia-national-careers.php`는 기본적으로 조회만 하며, `--apply`로 요청한 경력을 추가한다. 기존 레코드를 백업하고 트랜잭션 안에서 선수 ID와 이름, 대회·연도·국가·성적을 검증한다. 다시 실행해도 같은 경력을 중복 등록하지 않는다.

2026-10-02 적용 결과: 신규 6건, 기존 4건 유지. 세 선수의 `part=profile` API 응답도 확인했다.

홀의 2024 WBC 표기는 사용자의 확인에 따라 2024 프리미어12로 반영했다. 사용자가 확인한 네 대회만 남기도록 케네디의 기존 2017 WBC 레코드(PK 2203)는 별도 백업 후 삭제했다.

성적 출처:

- [2019 프리미어12 최종 순위](https://www.japan-baseball.jp/en/team/topteam/2019/premier12/overview.html)
- [2024 프리미어12 호주 경기 결과](https://baseball.com.au/premier12/)

- WBC는 `data/player-career/wbc-country-results.json`의 MLB 공식 일정·결과 출처를 사용했다.

전체 국가 매핑 검증은 동시에 추가된 별도 선수의 PK 4503이 기존 매핑에 없어 실패했다. 이번에 추가한 6건의 국가 매핑은 저장했고, WBC 결과 매핑 검증(61건, 변경 필요 0건)과 재등록 검사(신규 0건)는 통과했다. 다른 작업의 경력 레코드는 수정하지 않았다.
