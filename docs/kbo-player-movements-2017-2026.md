# 2017~2026 선수 이동 현황

2026-10-02 공식 [선수 이동 현황](https://www.koreabaseball.com/Player/Trade.aspx)의 GetTradeList API를 CLI/requests로 수집해 운영 DB에 반영했다. 전체 항목·전체 팀·전체 월, 페이지당 100건으로 마지막 페이지까지 조회했고 각 연도의 totalCnt와 실제 원문 행 수를 대조했다. 최신 공시일은 2026-09-28이다.

## 선수 테이블 갱신

- `kbo_player_data.backNo`: 공식 최신 프로필·이동 내역을 대조해 134명 갱신. 00·01 등 문자열 표기를 유지했다.
- 과거 이동 기록보다 최신 선수 프로필 번호가 있으면 현역·은퇴 선수 모두 확인된 번호를 사용했다. 은퇴 후 프로필이 코치 정보로 바뀐 경우 과거 이동 번호로 현재 값을 임의 대체하지 않았다.
- 개명 67건은 별도 캐시로만 처리해 `name`·`oldname`을 41명 갱신했다. 새 이동 테이블에는 넣지 않았다. 공식 프로필에 개명 전 이름이 남아 있으면 확인된 최신 개명 공시의 이름을 사용했다.
- 이전 이름의 적용일 안내는 이름에서 제외하고, 이미 존재하는 이전 이름은 중복 없이 보존했다. 기존 oldname 11자 제한보다 긴 체인은 최신 이전 이름만 저장하도록 했다. 전체 원문 체인은 캐시에 남는다.
- 선수 6,048명을 보완 전 백업과 비교해 name·oldname·backNo의 계획된 값이 전부 일치함을 확인했다. 최초 반영 직후 전체 컬럼 비교는 통과했다. 이후 별도 동시 작업에 의한 bat 4,021개, throw 4,021개, draft 2,607개, body 58개, birth 48개 변경이 확인돼 그대로 보존했다. 이 수집기의 UPDATE는 요청한 세 컬럼만 지정하며 다른 변경을 롤백하지 않는다. 선수 행 추가·삭제도 없다. 경기·시즌 합계 테이블과 DB 설정은 수정하지 않았다.

미확정 등번호 2건은 원문 저장 후 선수 번호 갱신을 보류했다. 유효 후보는 LG 투수 김태형 62918(1993년생), 67122(1998년생)이다.
